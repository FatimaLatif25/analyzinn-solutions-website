## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/FatimaLatif25/analyzinn-solutions-website.git
   cd analyzinn-solutions-website
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
   Visit `http://localhost:5173` to view the website.
